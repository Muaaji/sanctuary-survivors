# Marchand errant

Sprite original créé avec l’outil intégré imagegen, à partir d’une référence de marchand et du sprite existant du Paladin. PNG transparent : `assets/sprites/merchant/idle.png` (1122 × 1402). ## Prompt final

Use case: stylized-concept. Asset type: original transparent PNG game NPC sprite, for a dark medieval pixel-art top-down action roguelite. Input image 1 is ONLY a loose merchant concept reference (bearded traveler, bags, wares). Input image 2 is the ACTUAL game's hero sprite: match its mature gritty restrained pixel rendering and elevated three-quarter camera, not a cute cartoon. Create ONE original wandering merchant, full body, facing southeast towards viewer, readable stout silhouette, brown beard, muted moss-green wool tunic, worn dark brown leather vest and belt, large pack full of a rolled rug and two small bottles, boots, small lantern hanging from belt, holding a modest red potion in one hand and a pouch in the other. About 64 by 80 conceptual pixels, crisp block pixel clusters, limited earthy palette with pale warm edge highlights and tiny ruby / amber accents. Upright grounded neutral NPC idle pose, no action flourish. Composition: full figure centered and filling almost the entire canvas height, boots completely visible, compact pack silhouette; true transparent background including all corners, no painted scenery, no ground plane, no text, no speech bubble (the game draws it), no watermark, no logo, no border. Do not copy the reference drawing exactly. Avoid plush chibi proportions, smooth cartoon outlines, broad pastel colors, gradients, photorealism, tent or market stall.
